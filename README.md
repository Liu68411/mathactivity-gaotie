# 雾雪限速后，几点能到站？

G80 次 · 武汉 → 郑州东 · 专题三「高铁综合与实践」交互网页。

线上页面：<https://liu68411.github.io/mathactivity-gaotie/>

## 这个页面做什么

- 把 536 千米的行程切成「武汉停站 → 匀加速 → 正常速度匀速 → 匀减速至限速 → 限速运行 → 匀减速进站」；
- 所有加速、减速、制动都使用同一个加速度：0→350 千米/时用 15 分钟；
- 拖动停站时间、减速时刻、两段速度等假设，实时得到到站时刻和晚点分钟数；
- 用速度—时间图、路程—时间图（s-t）、分段表和 9 步具体算式说明估算过程；
- 保留第一次估计后，再拆开 2012 年 12 月 26 日的实际记录（16:13 到站，晚点 47 分），比较误差并解释原因；
- 一键反推「要让列车 16:13 到站，限速后平均速度大约是多少」；
- 自动生成小组汇报稿，支持复制和打印学习单（打印为 4 页课堂记录）；
- 老师想直接展示检验结果时，可在网址后加 `?revealed=1`；普通访问仍然先估后验。

## 默认模型

加速度由「15 分钟从 0 加速到 350 千米/时」标定：

```text
a = 350 ÷ 15 ≈ 23.3 千米/时/分
```

1. 武汉站计划停站 3 分钟，所以实际 13:42 到达后，估计 13:45 发车；
2. 从 0 匀加速到 300 千米/时，用时约 12.9 分钟，走 32.1 千米；
3. 以 300 千米/时匀速到出站第 60 分钟，即 14:45 开始减速；
4. 用同一加速度从 300 匀减速到 180，用时约 5.1 分钟，走 20.6 千米；
5. 以 180 千米/时通过限速段，最后从 180 匀减速到 0 进站，用时约 7.7 分钟，走 11.6 千米。

按默认假设：

- 降至限速前路程：32.1 + 235.7 + 20.6 = 288.4 千米；
- 限速段路程：236.0 千米；
- 限速段用时：236.0 ÷ 180 × 60 ≈ 78.7 分钟；
- 预计到站：16:16:31，向上取整报成 **16:17**；
- 比计划 15:26 晚 **51 分钟**；
- 实际 16:13 到站，估计偏晚 **4 分钟**；
- 若其余假设不变，限速后平均速度约需 188 千米/时，才能 16:13 到站。

页面还会画 **s-t 图**：横轴是时刻，纵轴是离武汉的累计路程。停站段水平，匀加速段向上弯曲，匀速段是直线，限速段斜率变小，进站制动段逐渐变平；曲线斜率就是速度。

## 本地预览

这是一个无构建步骤的静态站点，直接用浏览器打开 `index.html` 也可以；更推荐起一个本地服务器，保证 ES module 正常加载：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/>。
