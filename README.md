# 雾雪限速后，几点能到站？

G80 次 · 武汉 → 郑州东 · 专题三「高铁综合与实践」交互网页。

线上页面：<https://liu68411.github.io/mathactivity-gaotie/>

## 这个页面做什么

- 把 536 km 的行程切成「武汉停站 → 匀加速 → 正常速度匀速 → 匀减速至限速 → 限速运行 → 匀减速进站」；
- 所有物理量统一用 km 和 h，速度用 km/h；速度变化按“0→350 km/h 用 0.25 h”的同一规律等比例换算；
- 拖动停站时间、减速时刻、两段速度等假设，实时得到到站时刻和晚点分钟数；
- 用速度—时间图、路程—时间图（s-t）、分段表和 9 步具体算式说明估算过程；算式和表格中的每个物理量都标单位；
- 保留第一次估计后，再拆开 2012 年 12 月 26 日的实际记录（16:13 到站，晚点 47 分），比较误差并解释原因；
- 一键反推「要让列车 16:13 到站，限速后平均速度大约是多少」；
- 自动生成小组汇报稿，支持复制和打印学习单（打印为 4 页课堂记录）；
- 老师想直接展示检验结果时，可在网址后加 `?revealed=1`；普通访问仍然先估后验。

## 默认模型

物理量统一用 km、h、km/h，只使用两个基础关系：

```text
v平均 = (v初 + v末) ÷ 2
v = s ÷ t
```

速度变化用时按“0→350 km/h 用 0.25 h”的同一规律等比例换算，不引入加速度公式。

1. 武汉站计划停站 0.05 h，所以实际 13:42 到达后，估计 13:45 发车；
2. 从 0 匀加速到 300 km/h，用时 \(300÷350×0.25≈0.214\) h，走 \(150×0.214≈32.1\) km；
3. 以 300 km/h 匀速到出站后 1.000 h，即 14:45 开始减速，匀速用时 0.786 h，走 235.7 km；
4. 从 300 匀减速到 180 km/h，用时 \(120÷350×0.25≈0.086\) h，平均速度 240 km/h，走 20.6 km；
5. 以 180 km/h 通过限速段，最后从 180 匀减速到 0，用时 \(180÷350×0.25≈0.129\) h，平均速度 90 km/h，走 11.6 km；
6. 限速段路程 \(536−32.1−235.7−20.6−11.6=236.0\) km，用时 \(236.0÷180≈1.311\) h。

按默认假设：

- 降至限速前路程：32.1 + 235.7 + 20.6 = 288.4 km；
- 限速段路程：236.0 km；
- 预计到站：16:16:31，向上取整报成 **16:17**；
- 比计划 15:26 晚 **51 分钟**；
- 实际 16:13 到站，估计偏晚 **4 分钟**；
- 若其余假设不变，限速后平均速度约需 188 km/h，才能 16:13 到站。

页面还会画 **s-t 图**：横轴是时刻，纵轴是离武汉的累计路程。停站段水平，匀加速段向上弯曲，匀速段是直线，限速段斜率变小，进站制动段逐渐变平；曲线斜率就是速度。

## 本地预览

这是一个无构建步骤的静态站点，直接用浏览器打开 `index.html` 也可以；更推荐起一个本地服务器，保证 ES module 正常加载：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/>。
